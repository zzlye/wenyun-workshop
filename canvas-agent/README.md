# 西米露 Canvas Agent

## 简介

在画布中与助手对话，整理节点、引用素材，并继续生成图片、视频和文字。

## 如何使用

1. 在使用西米露的电脑上安装 Node.js 22 或更新的 LTS 版本。
2. 点击画布右侧 Canvas Agent 标题栏的“连接教程”，下载 Windows 启动包并解压。
3. 双击 `启动画布助手.cmd`。首次启动会准备依赖，若提示未登录，双击同目录的 `登录Codex.cmd` 完成登录。已有项目的用户也可以直接双击本目录中的同名文件。
4. 保持启动窗口打开，在 Canvas Agent 中填入窗口显示的服务地址，将已复制的令牌粘贴到连接令牌，点击连接。复制失败时从窗口手动复制。
5. 下次使用只需再次双击启动文件；重复打开会提示服务已经运行。
6. 在对话中描述任务。需要复用创作规范时，可在 Skills 中新建、编辑、启用或选择技能。

这里的连接令牌由本机助手生成，不是生图 API Key，服务地址也不是中转站地址。若浏览器询问本地网络访问权限，请允许当前站点访问。手机用户需在电脑上使用画布助手。

其他系统可在本目录执行 `npm ci`、`npm run build`、`npm start`；日常从项目根目录使用 `npm run agent` 也保持可用。

服务只供本机连接，每位用户使用自己的 Codex 登录和连接令牌。网站通过 Docker 部署时，也在用户自己的电脑上启动此服务。

## 功能介绍

- 对话：支持历史会话、图片附件、画布引用、推理强度、停止和操作确认。
- 画布操作：创建、修改、移动、连接、选择和删除节点，支持撤销。
- 创作：使用西米露已有的接口和模型生成图片、视频与文字。
- Skills：管理创作技能，从会话或画布提取技能草稿，选择技能辅助当前任务。
- 素材：查找提示词、检索素材和保存创作内容。
