# 上游来源

Canvas Agent 服务与 `src/infiniteCanvasSource/components/agent` 的对话、历史和 Skills 组件移植自 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)，上游提交为 `3a6b64b602ad062b29fac66902ed18a7ef5fd9dc`，源版本为 Canvas Agent 0.6.0，遵循 MIT 许可。许可原文见本目录 LICENSE。

西米露适配包括本机配置目录隔离、画布数据与生成参数转换、任务凭据过滤、分组及撤销集成、中文界面和移动端布局。西米露主版本仍为 0.4.13。
