# 西米露桌面版

在 Windows 电脑上使用西米露生图工坊、无限画布和 Canvas Agent，无需部署网站。

## 如何使用

1. 双击 `Wenyun-0.4.14-Setup-x64.exe`，选择安装文件夹，完成后打开西米露。希望数据存放在 D 盘时，请将软件安装到 D 盘。
2. 在设置中填写自己的接口地址和 API Key，或登录西米露账号。
3. 新建画布、导入图片，按原来的方式生成和编辑。
4. 需要画布助手时打开 Agent 面板，程序会自动启动并连接。首次使用可点击“登录 Codex”，完成浏览器中的登录；已有可用的 Codex 配置会继续沿用。
5. 在“设置 → 通用”开启“默认下载位置”，选择保存下载内容的文件夹。之后点击下载会直接保存到该位置，同名文件自动编号；也可以更改位置或关闭设置。

在“设置 → 数据管理”点击“打开文件夹”，可以查看本机保存的图片、视频及记录。默认保存在软件安装目录下的“输出”文件夹，不再固定保存到 C 盘的文档目录。

点击“更换位置”可以选择新的空文件夹。软件会复制并校验现有数据，完成后自动切换；原目录保留备份，迁移失败时继续使用原目录。升级旧版时，原先保存在文档目录的数据也会保留备份后迁移。

升级或卸载软件不会删除“输出”文件夹和另行选择的数据目录。请不要将存储位置放到软件的运行文件夹内。接口配置与登录状态仍由当前 Windows 用户单独保存。

旧网页版的数据不会自动读取。请先在网页版的“设置 → 数据”导出备份，再到桌面版同一位置导入。更换电脑前也应先导出备份。

## 功能介绍

- 生图工坊和无限画布沿用现有操作方式。
- 上传与生成的图片按原始格式保存到本地，保留分辨率和透明背景。
- 已保存到画布的音视频、画布内容、素材和任务记录保存在电脑中。
- 连接信息与素材分开保存，主要接口配置使用系统加密保护。
- Canvas Agent 自动启动和连接，无需手动填写本机地址和令牌。
- 退出前等待本地保存；有任务进行中时会提示确认。
- 不依赖网站部署，但生成图片、视频和模型对话仍需要可用接口及网络。退出软件会停止本机任务，不能作为后台持续生成服务。

## 软件更新

安装此版后，软件发现新版本会提示下载，也可以在“帮助 → 检查更新”中主动检查。下载完成后由你确认安装，有任务未完成或数据未保存时不会退出安装。旧版没有更新功能，需要先覆盖安装一次此安装包，已有数据会保留。

目前提供 Windows 64 位版本，未进行数字签名。
