# 西米露桌面版

在 Windows 电脑上使用西米露生图工坊、无限画布和 Canvas Agent，无需部署网站。

## 如何使用

1. 双击 `Wenyun-0.4.13-Windows-x64.exe` 打开软件。
2. 在设置中填写自己的接口地址和 API Key，或登录西米露账号。
3. 新建画布、导入图片，按原来的方式生成和编辑。
4. 需要画布助手时打开 Agent 面板，程序会自动启动并连接。首次使用可点击“登录 Codex”，完成浏览器中的登录；已有可用的 Codex 配置会继续沿用。

在“设置 → 数据”点击“打开文件夹”，可以查看本机保存的图片、视频及记录。默认位置是“文档”中的“西米露桌面版”文件夹。更换程序文件不会删除这些数据。

旧网页版的数据不会自动读取。请先在网页版的“设置 → 数据”导出备份，再到桌面版同一位置导入。更换电脑前也应先导出备份。

## 功能介绍

- 生图工坊和无限画布沿用现有操作方式。
- 上传与生成的图片按原始格式保存到本地，保留分辨率和透明背景。
- 已保存到画布的音视频、画布内容、素材和任务记录保存在电脑中。
- 连接信息与素材分开保存，主要接口配置使用系统加密保护。
- Canvas Agent 自动启动和连接，无需手动填写本机地址和令牌。
- 退出前等待本地保存；有任务进行中时会提示确认。
- 不依赖网站部署，但生成图片、视频和模型对话仍需要可用接口及网络。退出软件会停止本机任务，不能作为后台持续生成服务。

目前提供 Windows 64 位版本，未进行数字签名。
