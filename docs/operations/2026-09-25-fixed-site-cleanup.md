# 固定站点配置清理与任务复用排查

## 处理结果

- 删除已隐藏的服务商创建、复制、排序、编辑、协议和代理开关，以及配置链接导入和对应旧测试。
- 文运站、公益站的切换、密钥设置、模型选择、数据备份导入继续保留；旧链接中的配置和密钥参数会清除，不再导入。
- 修复历史任务复用只恢复参数却没有恢复模型的问题。先恢复历史模型，再校验尺寸和透明背景；跨站点临时复用保持当前站点和各站点密钥。
- 已提交任务的执行与恢复同样读取历史模型，避免站点后续切换模型改变原任务意图。
- 浏览器测试缺少 `window` 的问题通过补齐浏览器测试环境解决；图片 API 测试默认禁止未模拟的请求，避免测试访问线上接口。

## 异步与代理结论

文运站图片通过 `/image-tasks` 提交、查询和取回结果；已有任务凭据不会再次创建。查询短暂断网会继续查询，终态失败使用服务端错误。公益站仍走原有图片调用路径。

视频通过统一 NewAPI 任务接口创建和查询，刷新恢复使用原任务编号；前台等待超过 15 分钟保留等待状态。图片和视频返回协议不同，共同遵循保存任务编号、继续查询、不重复提交的原则，无需强行合成一个接口。

旧自定义服务商轮询测试不能代表这两条现有路径的状态。同源代理仍用于视频、账户登录、素材等请求；删除旧可配置开关不等于删除这些必要路由。
