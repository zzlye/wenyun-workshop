# 视频节点参考素材更新

## 简介

所有视频模型的本地参考素材先上传为临时公网 URL，再提交生成。网页与桌面共用实现，Docker 保持 0.4.13，桌面升级 0.4.24。

## 使用

按原方式连接图片、视频、音频或设置首尾帧即可。网页需要刷新，桌面需要更新；已经失败的任务由用户确认后重新提交。正在生成的任务继续查询原编号。

## 功能

- 覆盖已配置和未配置能力的全部视频模型，不再发送内联 Base64 或素材编号。
- 已有 HTTP(S) 地址保留；本地素材原字节上传，同次提交重复素材只上传一次，保留引用顺序。
- 上传失败停止创建任务，不静默丢素材、不自动重试收费生成。
- 临时素材单个最大 200MiB，有效期 24 小时；独立存储总量 4GiB，每个 Key 每小时 512MiB，最多 4 个同时上传。
- 服务端流式写盘，视频支持 HEAD 和 Range 读取；随机地址不包含 Key，过期自动清理。

## 排查与验证

- 旧逻辑以 `capability.configured` 决定是否上传，未配置模型仍发送 Base64，与上游 `VIDEO_INLINE_UPLOAD_DISABLED` 冲突。
- SSH 核对本站 `POST /v1/videos/uploads` 返回 404，现有 `/v1/video/assets` 只返回素材编号，未将上游接口提示当作本站已实现的接口。
- 新增 `/image-tasks/media-reference-uploads` 与匿名读取路径；桌面任务服务流式转发到站点托管服务。
- 使用模拟上游验证 URL 提交，正式验证只上传测试素材和读取，不重发客户请求、不产生视频生成费用。
