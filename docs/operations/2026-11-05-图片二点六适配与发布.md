# 西米露图片二点六更新

## 简介

网页、画布和桌面支持 GPT Image 2.6 Flare、Sunburst。桌面升级为 0.4.22，Docker 保持 0.4.13。

## 如何使用

选择包含 `gpt-image-2.6-flare` 或 `gpt-image-2.6-sunburst` 的模型后，可在图像设置调整品质、复杂度和输出格式。模型带渠道前后缀时同样适用。打开参考图编辑器可选择遮罩或彩色标注。

## 功能介绍

- 支持现有生图、图生图参数和复杂度选择。
- 支持 SVG 及 GIF 生成，GIF 可设置帧数、时长及逐帧尺寸。
- 支持透明彩色标注、画布编辑、历史详情与配置复用。
- 图片按实际格式预览和下载，切换模型时清理不适用参数。
