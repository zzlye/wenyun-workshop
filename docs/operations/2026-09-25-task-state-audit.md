# 任务复用、图片恢复与页面刷新排查

## 已修复的问题

- 连续点击两个任务的“复用配置”时，先点击的任务如果读图较慢，会覆盖后点击的任务。现在只应用最后一次复用，读图期间用户新输入的内容也会保留。
- 复用时参考图缺失会静默丢图、留下半套参数；本地存储读取失败还会泄漏异步异常。现在先完整读取参考图和遮罩，再恢复整套输入；读取失败保留原输入并提示。
- 图片查询或结果下载返回临时网关错误时，原来会被当成生成失败；下载连续中断五次后也会放弃已生成的结果。现在继续读取同一个任务，鉴权失败、过期和服务端明确失败仍立即结束。
- 服务端明确失败的错误包含 `timeout` 时，原来会被文字匹配误判为可恢复，反复查询。现在分别处理服务端终态与网络故障。
- 已提交的图片任务恢复时仍读取本地原图、遮罩，并受当前协议和异步开关影响。现在文运和画布持有完整任务凭据后只续查原任务，失效素材不再阻断恢复，也不重新进入协议回退。
- 直接打开或刷新 `/canvas/具体画布` 等地址时，生产入口资源被解析到错误的子目录，导致白屏。入口资源与网站图标、清单改用根目录地址。
