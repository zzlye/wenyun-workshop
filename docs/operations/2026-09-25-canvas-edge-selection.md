# 画布连线框选

## 使用方法

- 在画布空白处拖出选框，碰到的节点和连线一起选中；只框住线时不会选中两端节点。
- 按住 Shift 框选可以追加选择；按住 Shift、Ctrl 或 Command 点击连线可以追加或取消该线。
- 多选工具栏显示节点与连线数量，可点击删除，也可按 Delete 或 Backspace。
- 单独选一条线时保留曲线中间的剪刀按钮。只选连线不显示打组入口。
- Ctrl+Z 撤销整批删除，Ctrl+Shift+Z 重做；Esc 或点击空白清除选择。

## 修改说明

连线选中状态改为集合，框选根据实际贝塞尔曲线命中，不直接使用控制点包围盒。隐藏端点和悬空连接不参与框选。Shift 追加从按下鼠标时的选择快照计算，缩小选框会移除临时选中的对象。

节点和独立连线统一删除，保留已有节点清理、历史记录和保存流程；混选时流光继续朝向选中的节点。框选结束使用 pointerup 收尾，修复阻止默认行为后 mouseup 未派发造成的选框残留。
