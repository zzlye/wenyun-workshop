# 视频模型设置

视频节点会读取当前模型的可用选项。视频参数在节点内调整，设置页只保存视频接口密钥和模型选择。

## 如何使用

1. 在设置中填写视频密钥并获取模型列表。
2. 进入画布并选中视频节点，在节点设置中选择时长、清晰度、比例和生成模式。
3. 「更多参数」显示站点为该模型开放的选项。生成音频分为未指定、开启、关闭。
4. 当前组合没有可用渠道时，调整有提示的选项。切换模型不会悄悄改掉你的输入。

## 素材用途

- 文生视频只使用提示词；连接素材时会提示冲突。
- 多参考素材分别使用图片、视频和音频，保留各自顺序。
- 首尾帧使用第一张图片作为首帧、第二张作为尾帧，在参考素材中调整顺序。超过两张图片时需要先处理。
- 历史节点默认沿用原来的多参考素材用途。

是否支持音频参考、首帧加参考视频，以及带图时是否可以不填写提示词，以所选模型的配置为准。

## 等待与恢复

视频任务创建后会保留编号。刷新、断网或等待窗口结束后，会继续查询原任务，不重新生成。任务完成后获取视频；服务端明确返回失败时才显示失败。

模型选项读取失败会保留当前输入，可以重新读取。显示「模型能力未配置」时使用基础选项，实际支持情况由渠道决定。

模型适配由根用户在 NewAPI 的「系统设置 → 模型设置 → 视频适配」中维护，文运只展示参数，不提供协议编辑入口。
